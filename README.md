# 🎮 Melow Tic Tac Toe

Multiplayer emoji Tic-Tac-Toe built with **Flutter**, **Firebase Authentication (Anonymous)**, and **Cloud Firestore**.

## Features

- **Real-time online multiplayer** synced atomically via Cloud Firestore transactions
- **6-character room codes** (unambiguous alphabet, collision-checked) with one-tap copy
- **Flexible boards & tournaments**: 3×3, 4×4, 5×5, and 6×6 grids; Best-of-3 and Best-of-5 Melow Cup formats
- **Custom emoji marks**: 12 curated emojis with host/guest conflict prevention
- **Winning-line highlighting & haptics**: animated cell marks, glowing winning line, live turn indicators, and tournament trophy + instant rematch
- **Private room chat**: participant-only chat messages with 24-hour expiration timestamps
- **Material 3 Light & Dark themes** with system default and live toggle

## Getting Started

### Prerequisites

- Flutter SDK (`>=3.6.0` Dart SDK)
- Android Studio / Android SDK
- Node.js (`>=20`) and Firebase CLI (`npx -y firebase-tools@latest`)
- FlutterFire CLI (`dart pub global activate flutterfire_cli`)

### Run Locally

```bash
flutter pub get
flutter test
flutter run
```

### Build Android APK

```bash
flutter build apk --release
```

The release APK is generated at `build/app/outputs/flutter-apk/app-release.apk`.

### Deploy Firebase Configuration

```bash
npx -y firebase-tools@latest deploy --only auth,firestore
```

> **Optional TTL Policy**: To automatically purge expired chat documents server-side, enable a Firestore TTL policy in the Firebase Console on collection group `messages` using timestamp field `expireAt`. The app also filters expired messages client-side.

## Game Rules

- Connect **N** of your emoji marks in a straight horizontal, vertical, or diagonal line on an **N×N** board.
- Draws do not count toward decisive tournament wins.
- First to **2 wins** (Best of 3) or **3 wins** (Best of 5) wins the **Melow Cup 🏆**.
- Host starts Round 1; starting turn alternates every round.
